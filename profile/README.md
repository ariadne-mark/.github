# Ariadne Mark

**Free, open-source AI image and video labeling toolkit.**

Add invisible watermarks, signed C2PA provenance, a self-hosted verifier and a recovery registry to your media export pipeline. Ariadne Mark brings the tools, EU and California implementation guides, and versioned test evidence into one kit for generative product teams.

## Start with the current developer alpha

**[Download v0.7.2a1 →](https://github.com/ariadne-mark/ariadne-mark/releases/tag/v0.7.2a1)** · **[First export and verification →](https://github.com/ariadne-mark/ariadne-mark/blob/main/docs/start-here.md)**

- **Images and video:** supported JPEG/PNG and SDR H.264 MP4.
- **CPU backend:** qualified Linux x86-64 / Python 3.12 workflow; no GPU required. Connect it to your existing web or mobile backend.
- **Three video profiles:** Economy5s, Economy2s and Resilient, with different compute and recovery trade-offs.
- **Your infrastructure:** Python SDK/CLI, verifier UI/API and persistent recovery registry.

The project code is Apache-2.0. Third-party components and model weights keep their own terms. Compute, hosting and production signing or timestamp services are separate operating costs.
