# Ariadne Mark

**Open-source compliance toolkit for AI-generated images and video.**

We are building practical tools for content labeling: invisible watermarking, C2PA provenance, and verification, with an initial focus on EU and California requirements.

**Status: pre-alpha scaffold.** The SDK and public verifier are under development; no production release or blanket compliance guarantee is available. Our focus is CPU-first, self-hostable tools for images and video.
